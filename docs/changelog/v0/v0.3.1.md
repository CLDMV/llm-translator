# llm-translator v0.3.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

Version 0.3.1 is a maintenance release with no runtime changes. It patches two advisories in the dev-only lint toolchain and corrects four issue links in the v0.3.0 notes. The published package (`dist/`, `types/`, `bin/`) behaves exactly as v0.3.0.

---

## 🔒 Security & supply chain

- **`minimatch` and `katex` are overridden to patched versions** ([#97](https://github.com/CLDMV/llm-translator/pull/97)). `eslint` 10 only accepts `minimatch` 10.x and `@eslint/markdown` (through `micromark-extension-math`) only accepts `katex` 0.16.x, so neither advisory had an in-range fix and Dependabot could not open an update. `package.json` now carries `"overrides": { "katex": ">=0.19.1 <1.0.0", "minimatch": "^11.0.3" }`, as the other CLDMV packages do, which resolves [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249) (`minimatch`, pattern amplification) and [GHSA-238p-pmpm-9mq7](https://github.com/advisories/GHSA-238p-pmpm-9mq7) (`katex`, prototype pollution). Both packages are only reached by the lint step, and lint, including markdown lint, passes on the new versions.
