# llm-translator v0.16.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `next` → `master`

---

## Overview

Version 0.16.0 carries citations between protocols, serves Gemini models on Vertex AI, and closes the gaps left in the Gemini and Cohere native protocols that shipped in v0.15.0.

Existing setups work as before, except that citations now carry across protocols by default (`citations: "auto"`); set `citations: "none"` to leave them out of every reply. Audio output as mp3, opus or flac needs an optional peer dependency, and nothing else adds a dependency. None of the new upstream paths has been run against the real services yet; that is tracked in [#70](https://github.com/CLDMV/llm-translator/issues/70).

---

## ✨ Features

### Citations across Anthropic, Chat Completions and Responses ([#193](https://github.com/CLDMV/llm-translator/pull/193))

Anthropic `citations` on text blocks (and `citations_delta` while streaming), Chat Completions `url_citation` annotations and Responses API annotations now map both ways, whole and streamed, through one neutral shape. Over Chat Completions a citation rides as a standard `url_citation` plus a `citation` key the translator reads back, so nothing is lost on a round trip.

- `document` blocks with `citations.enabled` and `search_result` blocks keep their place and go through to Anthropic upstreams. An upstream that can't cite gets their text.
- New settings: `citations` (`auto` or `none`) and `documentCitations`, which asks for citations on documents made from OpenAI `file` parts.

See [docs/protocol-support.md](https://github.com/CLDMV/llm-translator/blob/master/docs/protocol-support.md#14-citations) and decision D-54. Resolves [#16](https://github.com/CLDMV/llm-translator/issues/16).

### Gemini models on Vertex AI ([#194](https://github.com/CLDMV/llm-translator/pull/194))

The `vertex` driver now serves Gemini as well as Claude. Under `auto` a `gemini-*` model goes over `google.gemini` to `publishers/google/models/{model}:generateContent` (and `:streamGenerateContent`) with the same Google auth, and every other model stays on Claude's `rawPredict`. Token counts use the publisher's `:countTokens`. See [docs/drivers.md](https://github.com/CLDMV/llm-translator/blob/master/docs/drivers.md#gemini-on-vertex-ai). Resolves [#186](https://github.com/CLDMV/llm-translator/issues/186).

### Cohere v2 gaps closed ([#195](https://github.com/CLDMV/llm-translator/pull/195))

- Citation-enabled `document` and `search_result` blocks go as Cohere `documents`, and Cohere's citations come back as `char_location` and `search_result_location`, in replies and streams. Citations of the model's thinking are written as `[n]` markers with a source list, and stripped again when the thinking is sent back.
- `tool_plan` becomes the start of the reply text. A named `tool_choice` is forced by offering only that tool, and `parallel_tool_calls: false` keeps the first call.
- Structured output next to tools or documents is sent as a system instruction, because Cohere refuses `response_format` there. It is not enforced.
- `logprobs`, `cached_tokens`, value clamping, effort budgets, the failed-tool-result error object, and token counts from Cohere's tokenizer. `logit_bias` and `top_logprobs` are dropped; Cohere has no field for them.
- `n` > 1 fans out over the Compatibility API, and under `auto` a request that needs something only `cohere.chat` has goes native.

See [docs/drivers.md](https://github.com/CLDMV/llm-translator/blob/master/docs/drivers.md#cohere), [docs/protocol-support.md](https://github.com/CLDMV/llm-translator/blob/master/docs/protocol-support.md#13-cohere-v2-chat) and decisions D-55 and D-56. Resolves [#189](https://github.com/CLDMV/llm-translator/issues/189).

### Gemini native protocol gaps closed ([#196](https://github.com/CLDMV/llm-translator/pull/196))

- Grounding and citation metadata come back as citations, whole and streamed. Gemini's UTF-8 byte offsets are turned into string positions.
- Computer use maps both ways between Anthropic's computer tools (the older `computer_*` tools and the toolset form) and Gemini, including switched-off members. `settings.gemini.computerUse` adds prompt-injection detection, disabled safety policies, the environment and extra exclusions.
- An action Gemini flags for confirmation is asked through the client's `AskUserQuestion`-style tool (or `settings.gemini.confirmationTool`). Allow runs it with Gemini's safety acknowledgement, Deny reports the decline back to Gemini, and an answer that doesn't match the question is refused with `unconfirmed_computer_action`. Without a prompt tool the question is asked in plain text.
- Audio output as mp3, opus or flac, cache creation tokens, `n` up to 8 answered by Gemini itself, safety settings, output modalities, cached contents, built-in tools, generated images and code output.

See [docs/drivers.md](https://github.com/CLDMV/llm-translator/blob/master/docs/drivers.md#gemini-native-api), [docs/protocol-support.md](https://github.com/CLDMV/llm-translator/blob/master/docs/protocol-support.md#12-google-gemini-generatecontent) and decisions D-57 to D-59. Resolves [#188](https://github.com/CLDMV/llm-translator/issues/188).

## 🔧 Dependencies

- New optional peer dependencies for Gemini audio output: `wasm-media-encoders` (mp3), `opusscript` (opus) and `libflacjs` (flac). Without the matching one, a request for that format fails with `audio_encoder_unavailable` (501) naming the package.

## Upgrade notes

- No breaking changes.
- Citations now carry across protocols by default. Set `citations: "none"` to leave them out of every reply.
- To get Gemini audio as mp3, opus or flac, install the matching package: `npm i wasm-media-encoders`, `npm i opusscript` or `npm i libflacjs`.
