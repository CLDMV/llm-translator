# llm-translator v0.15.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `next` → `master`

---

## Overview

Version 0.15.0 adds the last two native protocols from the initial set: Google's Gemini `generateContent` API and Cohere's v2 chat API. Both are reached from either front, Anthropic Messages or OpenAI Chat Completions.

Nothing changes for an existing setup. Each native protocol is used only when an upstream sets `api` to it; under `api: "auto"` Gemini still goes through Google's OpenAI-compatible endpoint, and the new Cohere driver goes through Cohere's Compatibility API. No new dependencies. Neither protocol has been run against the real service yet; that is tracked in [#70](https://github.com/CLDMV/llm-translator/issues/70).

---

## ✨ Features

### Google Gemini native protocol ([#187](https://github.com/CLDMV/llm-translator/pull/187))

The `gemini` driver gets a second protocol, `google.gemini` (aliases `gemini` and `google`), selected with `api: "gemini"`. Requests go to `generateContent` and `streamGenerateContent?alt=sse` with the model in the URL, and the key is sent as `x-goog-api-key`. Token counts use `countTokens`, with the usual estimate as a fallback, and `GET /models` is answered from Google's native model list.

- Text, images, tools and structured output are mapped. A base64 PDF is sent whole as `inlineData` and read by Gemini itself, instead of being expanded into text and page images.
- Thinking uses `thinkingBudget` on Gemini 2.5 and `thinkingLevel` on Gemini 3 and later, which refuse a budget. An effort is mapped to whichever the model takes.
- Thought signatures are carried through the reasoning side channel and put back on the part they came from, so Gemini 3 tool turns work across a round trip. When a client dropped a signature, Google's placeholder is sent on the turn's first function call.
- Google's error envelope is now shared with the Vertex AI driver.

Gaps that remain are listed in [#188](https://github.com/CLDMV/llm-translator/issues/188), and Gemini models on Vertex AI in [#186](https://github.com/CLDMV/llm-translator/issues/186). See [docs/drivers.md](https://github.com/CLDMV/llm-translator/blob/master/docs/drivers.md#gemini-native-api) and [docs/protocol-support.md](https://github.com/CLDMV/llm-translator/blob/master/docs/protocol-support.md#12-google-gemini-generatecontent). Resolves [#48](https://github.com/CLDMV/llm-translator/issues/48).

### Cohere driver and the v2 chat protocol ([#191](https://github.com/CLDMV/llm-translator/pull/191))

The new `cohere` driver binds to `api.cohere.com` and `api.cohere.ai`, or to `backend: "cohere"`. Under `api: "auto"` it talks Chat Completions to Cohere's Compatibility API at `/compatibility/v1/chat/completions`, removing the fields Cohere doesn't support and mapping `reasoning_effort` to the two values it takes. With `api: "cohere"` it uses the new `cohere.chat` protocol at `/v2/chat`.

- Text, images, tools (including streamed tool-call arguments), thinking and structured output are mapped. Cohere can't force one named tool, so a `tool_choice` naming the only tool is sent as `REQUIRED`, and any other named choice is dropped. Cohere's `tool_plan` text is not carried over.
- The upstream's `sampling` setting passes Cohere's own top-level fields (`safety_mode`, `citation_options`, `priority`, `strict_tools`, ...) through as given.
- `GET /models` is answered from Cohere's model list filtered to chat models. Token counts are estimated, because `/v1/tokenize` takes one raw string rather than a chat.
- A reply that finishes with `ERROR` becomes a 502 and `TIMEOUT` a 504.

Gaps that remain are listed in [#189](https://github.com/CLDMV/llm-translator/issues/189); citations belong with [#16](https://github.com/CLDMV/llm-translator/issues/16). See [docs/drivers.md](https://github.com/CLDMV/llm-translator/blob/master/docs/drivers.md#cohere) and [docs/protocol-support.md](https://github.com/CLDMV/llm-translator/blob/master/docs/protocol-support.md#13-cohere-v2-chat). Resolves [#49](https://github.com/CLDMV/llm-translator/issues/49).

## Upgrade notes

- No breaking changes. Existing upstreams bind and behave as before.
- To use Gemini's native API, set `api: "gemini"` on a Gemini upstream. To use Cohere, add an upstream with `url: "https://api.cohere.com"` and your key; set `api: "cohere"` for the native v2 chat API.
