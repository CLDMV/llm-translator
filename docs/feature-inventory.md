# Feature inventory

Every feature found while researching the protocols, servers and clients this library touches, with its current status. Each row has a stable identifier (`FI-###`) that issues and documentation refer to. Identifiers are never reused or renumbered; new features are appended.

Statuses: **implemented** (works as described in [protocol-support.md](protocol-support.md)), **partial** (works with caveats, see the note), **not implemented** (no support yet, tracked by an issue), **out of scope** (deliberately unsupported, for example features with no counterpart on local servers).

Source abbreviations: `CC` Claude Code wire inventory; `ANT` Anthropic API inventory; `OAI-CHAT` OpenAI Chat Completions inventory; `OAI-OTHER` OpenAI non-Chat inventory; `vLLM` vLLM inventory; `LAND` landscape inventory; `DESIGN` the design contract. Section numbers refer to those inventories.
